# 🍎 iPhone 15 Pro Website Clone

A responsive Apple iPhone 15 Pro website clone built with **React.js, Three.js, React Three Fiber, GSAP, and Tailwind CSS**. This project recreates Apple's premium product presentation with interactive 3D iPhone models, smooth animations, dynamic color and size selection, and immersive visual experiences.

The project focuses on modern frontend development, 3D visualization, animation, responsive design, and reusable React components.

## ✨ Features

* **🎨 Interactive 3D iPhone Models** — Explore detailed iPhone 15 Pro models rendered using Three.js and React Three Fiber.
* **📱 Dynamic Color Selection** — Switch between available iPhone colors and preview corresponding product finishes and images.
* **📏 Dynamic Size Selection** — Switch between available model sizes with animated transitions.
* **🎬 Smooth GSAP Animations** — Create polished transitions, scroll-based animations, and engaging visual effects using GSAP.
* **🎞️ Custom Video Carousel** — Interactive video carousel with GSAP-powered transitions.
* **📱 Fully Responsive Design** — Optimized layouts for desktop, tablet, and mobile devices.
* **🧩 Reusable Component Architecture** — Modular React components for maintainable and organized code.
* **🎮 Interactive 3D Experience** — Rotate and explore product models from different angles.
* **🎨 Modern UI** — Apple-inspired layouts, typography, spacing, and product presentation.
* **⚡ Fast Development** — Powered by Vite for a fast development server and optimized production builds.

## 📸 Project Highlights

### Interactive 3D Product Viewer

The website uses a 3D iPhone model to create an interactive product-viewing experience. Users can explore the device from different angles and switch between available product configurations.

### Dynamic Product Customization

React state manages the selected product configuration, allowing users to change colors and sizes through interactive controls.

### Smooth Animations

GSAP powers visual transitions and interface animations, helping create a polished product presentation inspired by Apple's website.

### Responsive User Interface

Tailwind CSS utilities help maintain a consistent layout and viewing experience across different screen sizes.


## 🎮 How to Use

1. Open the website in your browser.
2. Explore the interactive 3D iPhone model.
3. Rotate the device to view it from different angles.
4. Select an available color to preview another product configuration.
5. Switch between available sizes.
6. Explore the animated product sections and video carousel.
7. Resize the browser to experience the responsive layout.

*Available options depend on the product configurations and assets included in the project.*
